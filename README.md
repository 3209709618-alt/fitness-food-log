# 食衡 · 好好吃，好好练

一个独立的、手机优先的健身饮食记录网站。无需前端依赖，数据默认保存在当前浏览器。

## 本机运行

需要 Node.js 22 或更新版本：

```powershell
npm run dev
```

打开 <http://127.0.0.1:4180>。

## 手机访问

GitHub Pages 静态版可通过公网 HTTPS 打开，浏览器本地记录、目标计算、自定义食物和 JSON 备份均可使用。将项目推送到 GitHub 公共仓库后，发布工作流会在每次推送 `main` 时部署允许公开的网页文件；若首次发布未启用 Pages，请在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。GitHub Pages 不能运行 Node 代理，因此静态版不提供 USDA 在线搜索；若要启用该功能，需要另行部署 Node 服务并配置 `USDA_API_KEY`。

本机网址与 GitHub Pages 是不同的浏览器存储地址；换设备或换网址时，请先在旧网站的「目标与设置」导出 JSON，再在新网站恢复。即使使用同一手机，清理浏览器数据也可能删除记录。

可选启用 USDA FoodData Central 搜索：复制 `.env.example` 为 `.env`，填写自己申请的 `USDA_API_KEY` 后重新启动。密钥只保存在服务器端；不要提交 `.env`。没有密钥时，目标计算、自定义食物、本地记录和 JSON 备份仍可使用。

## 记录与食物数据

身体资料、目标、自定义食物和每日记录保存在浏览器的 `localStorage` 中。导出 JSON 后，用户可在另一份网站副本中恢复。恢复备份会替换当前资料、目标、食物和记录，因此恢复前会校验格式并确认。

`data/foods.json` 当前为空：食物成分表的准确来源与公开再分发许可仍需核验。应用不会用无来源示例数据冒充权威本地食品库。你可以按包装标签录入，也可以在服务器配置 USDA 密钥后在线查询。每条自定义记录都标记为用户自填、未经机构核验。USDA 查询仅提交食物搜索词；个人资料和饮食记录不会随请求发出。

热量参考使用 Mifflin–St Jeor 公式和活动系数。减脂、维持、增肌对应 90%、100%、110% 的产品默认值；蛋白质 1.6 g/kg，脂肪为热量的 30%，剩余热量分配给碳水。以上均为可修改的估算，不是医疗建议。
